<h2>Description</h2>

This is a peripheral bundle of halloween stuff I made on onshape, including:
Candy,
Lollipop,
Treat bag,
Mentos,
and a Batarang

<br>
As well as an assembly featuring them all!!!

<h2>Features</h2>

Can be printed as decor
<br>
Looks nice <br>
Treat bag can be used to store actual treets (once you've printed it of course)!<br>

<h2>Uses</h2>
Here are some uses for the stuff I made

Candy - Can be used to troll people <br>
Lollipop - See above <br>
Treat bag - Cool decor, can be used to store actual candy and more!<br>
Mentos - Looks realistic enough to eat
Batarang - For that one annoying sibling of yours <br>


<h2>Tech and tools</h2>

This was all designed by me using onshape, with VS code to write the readme :), as well as github, for I wonder what

<h2>Yap from me </h2>

Basically I've used onshape before for basic stuff, such a a fish tank etc. But I've never really experimented with organic shapes fully by myself too much. So I thought that it'd be a nice time to try this time around, which I did! I also haven't made CAD projects in a bit, and didn't wanna get too rusty, so making this project was really nice for me<br><br>

I also used this as a chance to play around with onshape, setting colour, materials, transparency etc. <br>


Also the 3 mentoses were actually made using different methods! One was using a circle, the other was using a square, which then I revolved, and the last one was by using a 3 point spline!
<br>

Making the candy wrapper was genuine horror. I thought they looked random and really didn't even know what plane to start the sketch on! Figured out that I could revolve it eventually tho<br>
